# Security

If you find a vulnerability in jevusecases.com, please report it privately through this repository's
[Security tab](https://github.com/theSekyi/jevusecases/security/advisories/new) rather than opening a public issue.

Include what you found, the steps to reproduce it, and what an attacker could do with it. You can expect a first reply within a few days.

Please don't test against other people's data, and don't run automated scans that send heavy traffic to the live site.
